# 🛍️ BimBam Buy — Assistente Inteligente de Atendimento ao Cliente

Projeto desenvolvido como solução do **Challenge de Inteligência Artificial / Oracle Cloud Infrastructure (OCI)** promovido pelo programa ONE (Oracle Next Education) em parceria com a Alura.

---

## 📌 Descrição do Projeto

O assistente foi desenvolvido para atuar como canal oficial de suporte da loja virtual fictícia **BimBam Buy**, respondendo dúvidas com base estrita na documentação corporativa oficial (políticas de frete, prazos de entrega, garantias, cancelamentos e formas de pagamento).

---

## 🛠️ Tecnologias Utilizadas

* **Python 3.10+**
* **Streamlit**: Interface web interativa para o chat.
* **PyPDF**: Extração do conteúdo da documentação oficial em PDF.
* **Google Gemini API (gemini-3.6-flash)**: Raciocínio, compreensão contextual e geração de respostas objetivas.
* **Docker**: Conteinerização para garantir portabilidade da aplicação.
* **Oracle Cloud Infrastructure (OCI)**: Implantação e hospedagem em instância Compute Always Free.
